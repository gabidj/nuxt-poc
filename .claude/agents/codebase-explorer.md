## Data Flow Understanding

### Upload Flow
```
VideoUpload.vue
  │
  ├─► POST /api/upload/init
  │     └─► Creates session, returns uploadId
  │
  ├─► POST /api/upload/chunk (loop)
  │     └─► Saves each 10MB chunk
  │
  └─► POST /api/upload/finalize
        └─► Combines chunks, returns UUID
```

### Processing Flow
```
step2.vue
  │
  ├─► POST /api/process/{id}/audio
  │     └─► FFmpeg extracts audio → audio.m4a
  │
  ├─► POST /api/process/{id}/frames (parallel)
  │     └─► FFmpeg extracts frames → frame_*.jpg
  │
  ├─► POST /api/process/{id}/transcript (after audio)
  │     └─► OpenAI Whisper → whisper.json
  │
  └─► POST /api/process/{id}/details (after transcript)
        └─► OpenAI GPT → details.json
```

### Results Flow
```
results.vue
  │
  ├─► SummaryCard ──────► GET /api/result/{id}/details
  ├─► ShortDescriptionCard ► GET /api/result/{id}/details
  ├─► LongDescriptionCard ─► GET /api/result/{id}/details
  ├─► AgendaCard ──────────► GET /api/result/{id}/details
  ├─► TranscriptCard ──────► GET /api/result/{id}/transcript
  └─► QuizCard ────────────► GET /api/result/{id}/details
```

## Common Questions

### "Where is X functionality implemented?"

| Feature | Location |
|---------|----------|
| Video upload UI | `components/VideoUpload.vue` |
| Chunked upload backend | `server/api/upload/*.ts` |
| Audio extraction | `server/api/process/[id]/audio.ts` |
| Frame extraction | `server/api/process/[id]/frames.ts` |
| Transcription | `server/api/process/[id]/transcript.ts` |
| AI content generation | `server/api/process/[id]/details.ts` |
| Processing orchestration | `app/pages/step2.vue` |
| Results display | `app/pages/results.vue` + `components/cards/*` |
| Upload session management | `server/utils/uploadSessions.js` |

### "How does the upload process work?"

1. User drags/drops file → `VideoUpload.vue`
2. Component validates file type (video/*) and size (max 5GB)
3. Calls `POST /api/upload/init` to create session with UUID
4. Loops through file in 10MB chunks, calling `POST /api/upload/chunk`
5. Calls `POST /api/upload/finalize` to combine chunks
6. Returns UUID, navigates to `/step2?file={uuid}`

### "What components display Y data?"

| Data Type | Component | Endpoint |
|-----------|-----------|----------|
| Summary | SummaryCard | `/api/result/{id}/details` |
| Short description | ShortDescriptionCard | `/api/result/{id}/details` |
| Long description | LongDescriptionCard | `/api/result/{id}/details` |
| Agenda | AgendaCard | `/api/result/{id}/details` |
| Transcript | TranscriptCard | `/api/result/{id}/transcript` |
| Quiz | QuizCard | `/api/result/{id}/details` |

### "How do the processing stages connect?"

Sequential with parallel frames:
1. **Audio** and **Frames** start immediately (parallel)
2. **Transcript** waits for Audio to complete (needs audio file)
3. **Details** waits for Transcript to complete (needs transcript text)
4. When all complete → 3 second countdown → redirect to results

## Quick Reference

### File Storage Path
```
public/data/uploads/{uuid}/
```

### UUID Format
- Pattern: `[a-zA-Z0-9-_]+`
- Generated by: `crypto.randomUUID()`

### Chunk Size
- Size: 10MB (10 * 1024 * 1024 bytes)
- Max file: 5GB

### Frame Rate
- Extraction: 2 frames per second
- Format: JPG, quality level 2

### Audio Format
- Codec: AAC
- Bitrate: 48kbps
- Format: M4A
